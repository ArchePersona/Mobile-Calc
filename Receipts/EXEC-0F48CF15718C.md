## Request

**Project:** Mobile calculator application
**Objective:** Provide a simple, intuitive calculator for mobile devices with basic arithmetic operations.

**Deliverables:**
- Source code repository
- Build scripts for Android APK and iOS IPA
- Basic unit tests for arithmetic logic
- README with build and run instructions

**User Experience:**
- Large, touch-friendly buttons
- Responsive layout for various screen sizes
- Light and dark theme support
- Haptic feedback on button press

**Integrations:**
- None required for core calculator.

**Future Expansion:**
- Scientific functions (sin, cos, log, etc.)
- Memory storage (M+, M-, MR, MC)
- History of calculations
- Customizable themes

**Safety & Constraints:**
- App must be free of ads and in-app purchases for this scope.
- Comply with platform store guidelines.
- Minimal permissions: none required.

**Core Capabilities:**
- Addition, subtraction, multiplication, division
- Clear (C) and backspace functionality
- Decimal point support
- Display of current expression and result

**Assumptions:**
- Target platform: Android and/or iOS using a cross-platform framework like Flutter or React Native.
- User will have touchscreen input.
- No need for advanced scientific functions initially.

**Open Questions:**
- Which cross-platform framework to use? (Flutter, React Native, Ionic)
- Target minimum OS versions?
- Should the app support landscape orientation?

**Data:**
- No persistent data required; calculations are ephemeral.
- Optional: store last expression in local state for session persistence.
